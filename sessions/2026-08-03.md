## COCTAccounts: global one-line (accounts.sol)
Added a `Line` structure per owner spec — a GLOBAL straight chain in registration order, separate
from the referral tree:
- `struct Line { address parent; address child; }` + `mapping(address => Line) public line` + `address public lastRegistered` (tail) + `event LineLinked`
- Constructor seeds `lastRegistered = root` (root = head; line[root] = (0,0))
- `addUser`: new account's `parent` = previous last-registered; that member's `child` → new account; new account becomes the tail (its `child` = address(0) by default)
- `removeUser`: splices the node out (relinks parent↔child, moves tail back) to keep the chain intact — **consistency behavior beyond the add-only spec; confirm if you want different removal semantics**
- `getUser`/`UserView` extended with `lineParent` / `lineChild`
- Independent of the referral tree (`updateAffiliateParent` doesn't touch it)
- `moveLine(user, afterNode)` (onlyAdmin, O(1)) repositions a member — e.g. a,b,c,d,e,f,g → `moveLine(f, b)` → a,b,f,c,d,e,g; built on reusable `_unlinkLine` / `_insertLineAfter` helpers (removeUser now reuses `_unlinkLine`)
- ✅ Compiles standalone (forge/solc 0.8.36); no line-specific tests yet
